# Feature Ideas for Doppelkopf Count Training

## Game Variations

### Different Counting Modes

All counting-mode variations previously listed here are implemented:

- **Single Game**: Practice a single round at your own pace with a customizable
  number of cards.
- **Survival**: Build a streak through progressively larger rounds; one incorrect
  answer ends the run.
- **Timed Challenge**: Complete a fixed-difficulty round before a configurable
  time limit expires.
- **Tutorial**: Follow an interactive, step-by-step introduction to card values,
  counting examples, and game flow.
- **Reverse Counting**: Start from the round's total card value and subtract each
  counted card until reaching zero.
